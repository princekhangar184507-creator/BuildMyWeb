UPLOAD:
1. Upload everything in this folder to the BuildMyWeb repository root.
2. Keep the homepage filename exactly: index.html
3. Keep the assets folder in the same root.

SEARCH CONSOLE:
Google Search Console may give you a unique verification HTML file. That file is NOT included here because its filename/token is unique to your Google account.
Upload Google's downloaded verification file to the repository root, exactly as downloaded, then tap Verify.
